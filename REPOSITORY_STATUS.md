# Repository status

The current implementation targets OKF 0.3 using an independent early-years
semantic profile. It preserves the 22-concept, 23-assertion fictional snapshot
from 5 September 2026. The historical 0.2 control is a separately hashed input.

The current acceptance requirements and three logical bundle scopes are in
the [publication contract](okf.publication.json). Completion requires actual
Reader journeys, source and graph parity, responsive walkthroughs, all public
bytes and exact release read-back. Historical preparation receipts do not prove
these new gates have passed.

This repository is a teaching and assurance fixture. It is not an operational
early-years service, a calibrated linkage system or a clinical decision tool.
No personal information, live referrals or paid model calls form part of the
migration. The bootstrap adoption check currently compares some existing files
with starter templates; that limitation does not authorise overwriting this
repository's reviewed custom profile or established validation workflow.
