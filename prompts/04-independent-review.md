# Independent review — criticise the frozen artefact, not the author's intention

Review the named source snapshot, profile, generated bundle and execution receipts read-only. Do not repair the implementation while reviewing. Do not treat another model's agreement as independent source evidence. Distinguish source independence, implementation independence and a fresh review context.

Take ten representative assertions, including every high-risk candidate or action-state relation in the small fixture. Reconstruct each from the exact cited source file and locator. Check source/predicate/target meaning, direction, scope, derivation, time, rights, review status and what the evidence does not establish.

Check the complete identifier/route registry and direct-triple/assertion reconciliation with deterministic tools. Look specifically for an unreviewed identity link emitted as an ordinary RDF assertion; duplicated or overwritten claim events; proposed support presented as completed; absent records presented as absent need; fabricated human review; undefined context terms silently dropped; and presentation grouping promoted into ontology.

Examine actual consumer results, not merely JSON Schema success or the fallback preview. Verify that receipts name the exact tested bytes, tool versions and commands. A screenshot without a source/route identity is not release proof. Code/hash checks do not establish narrative truth; review substantive prose as well.

Report `review-findings.json` with severity, affected file/assertion, reproducible evidence, violated contract and a bounded correction. Classify findings as blocking for synthetic demo, blocking for production only, or non-blocking improvement. Return `review-summary.md` under 800 words. If there are no blocking findings, say which tests and source samples support that judgement and which domains remain untested.

Do not widen the scope into a replacement architecture unless a concrete finding requires it. Preserve the frozen candidate; fixes create a new candidate and rerun only the affected dependency closure plus final acceptance.
